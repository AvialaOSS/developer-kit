# DatePickerField

## 3.1.0

### Fixed
- 时间滚轮的程序滚动补齐结束兜底，避免缺少 scrollend 时阻塞后续用户选值。
- 时间滚轮支持像素、行和页三种滚轮输入单位，并随当前密度读取尺寸。
- 时间滚轮仅拦截可消费的纵向选择手势；空列表、单项列表、有限列边界、Ctrl 缩放及横向滚动不再被无条件拦截。

- 禁用输入框保持背景不透明，内容槽与内部文字分层消费组件透明度 Token，避免整体淡化背景或重复淡化占位符。

### Fixed
- 时间滚轮使用实例级选项 ID，避免同页同名滚轮的无障碍引用冲突；受控值不在选项中时不再生成无效活动后代引用。
- 循环滚轮只向辅助技术声明一个选中项，重复渲染行保持原有视觉状态。

### Fixed
- 输入触发器悬浮背景在局部主题中重新解析，保留显式 input-bg-hover 覆盖。

### Changed
- 年月及时间滚轮选中高亮补齐共享底部内阴影，沿现有 Figma 引用链跟随效果模式。
- 年月滚轮选中背景与文字消费 ScrollPickerItem Token，渐隐颜色跟随年月面板局部背景；保留显式旧选中配色覆盖。
- 年月滚轮按选项高度与间距计算滚动步长，接入年月列纵向留白及 ScrollPickerItem 尺寸、普通文字和透明度；密度改变行高时重新对齐选中值。
- 年月选择容器接入独立的背景、圆角、边框及年月列横向留白 Token，选中层与滚动内容保持相同横向边界。
- 日历外层背景、边框、圆角与留白消费 DatePickerSelectMenu Token；底部操作区消费 DatePickerList 留白和 SegmentatorGroup 表面 Token，滚轮渐隐跟随局部日历背景。
- 日历标题留白、圆角、文字与星期标题配色接入组件 Token；分离列表与日期网格间距，面板高度在局部主题中随日期留白和共享字体指标计算。
- 日期输入框两档尺寸、图标槽、圆角、背景及激活边框接入独立 Token，时间输入框保留自身迁移路径；禁用透明度暂沿用原规则。
- 日期单元格的留白、间距、内外圆角、选中/未选中文字、选中背景、今日标记和跨月透明度消费组件 Token；保留显式旧颜色及圆角覆盖。

### Fixed
- 旧占位符透明度默认声明移入兼容层，避免遮蔽 DatePickerInput 自身 Token；显式旧覆盖继续生效。
- 共享输入字号、行高及图标插槽默认高度在局部主题中解析，避免继承外层密度的已解析值；显式旧覆盖继续优先。

### Fixed

- 未单独配置时间时，输入框与时间轮跟随所选 Date 的时分，并响应外部受控值更新，避免错误显示默认 17:00；显式 timeValue / defaultTimeValue 继续优先。

## 3.0.0

### Fixed
- 日历面板不再使用 `role="application"`，改为 `role="group"`，屏幕阅读器恢复常规浏览模式
- 日期网格补齐 `role="row"` 行语义，配合已有的 `role="gridcell"` 与方向键 / Home / End / PageUp / PageDown 导航

## 2.8.0

### Fixed

## 2.6.1

### Changed
- 日历面板上一月 / 下一月导航图标改为 `direction/arrowLeftLight` 与 `direction/arrowRightLight`
- 导航箭头按压缩小，松开后沿翻页方向飞出并由对侧飞入
- 月/年与时间滚轮：鼠标滚轮步进更灵敏，可一次跨多格，并允许打断进行中的平滑滚动
- loop 滚轮按当前位置最短路径滚动，跨 0/末项不再整段甩回；选中字色经固定高亮框裁切随列表滚动，停稳后对准居中
