# ScrollPicker

## [Unreleased]

### Fixed
- 已在边界时重复按 Home 等无位移操作不再留下程序滚动标记，下一次手动滚动可正常选值。
- 程序触发滚动也启动结束兜底；未收到原生 scrollend 时仍能恢复后续用户滚动选值，且不重复提交程序选值。
- 滚轮按 deltaMode 换算像素、行和页单位，行/页输入随当前行距与列视口尺寸计算，避免被误当成像素。
- 不再拦截 Ctrl 缩放、纯横向滚动或其他已处理的滚轮事件；空列表、单项列表及有限列外向边界允许原生滚动传递。
- 循环模式仅将活动后代对应的选项声明为选中，避免同一值的多个重复行同时被读作选中；视觉高亮保持原有行为。

### Fixed

- 空选项或受控值不在当前选项中时，不再向辅助技术提供无效的活动选项引用。
- 修复循环列选中项与首段副本使用重复 ID 的问题，辅助技术的活动选项指向中间段选中项。

### Changed

- 选项、高亮与裁切高度随共享行高和组件内边距 Token 变化；密度或局部尺寸变化后保持当前值居中，显式旧高度覆盖仍有效。

- 选中高亮补齐 Figma 已绑定的底部内阴影，跟随共享效果 ON/OFF，并支持显式 scroll-picker-item-shadow 覆盖。

- 样式改为直接消费 Components Figma 中的 ScrollPicker 组件级 Token，并保留旧 CSS 变量作为兼容覆盖入口；亮色、暗色与密度模式继续沿基础与语义变量传导。

## 3.0.0

### Fixed
- `loop={false}` 的列滚到首尾后不再吞掉滚轮事件，页面可以继续滚动；loop 列行为不变

## 2.6.1

### Changed
- 滚轮列：鼠标滚轮步进更灵敏，可一次跨多格，并允许打断进行中的平滑滚动
- loop 列按当前位置最短路径滚动；选中字色经固定高亮框裁切随列表滚动，停稳后对准居中
