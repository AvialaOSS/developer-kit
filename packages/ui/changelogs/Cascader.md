# Cascader

## [Unreleased]

### Added
- 新增 CascaderSearch：复用输入框，支持搜索行留白/圆角 Token、方向键进入结果及 Escape 关闭；过滤逻辑由调用方控制。

### Fixed
- 菜单行悬浮和键盘高亮背景在局部主题解析；保留 cascader-item-highlight-bg 及共享 Select 覆盖优先级，选中与未选中行使用相同交互背景。
- 普通、标题及选中项的左右图标分别消费独立图标颜色 Token，不再被默认文字颜色遮蔽；旧前景色覆盖仍保留。
- 选中项阴影跟随局部主题效果开关；菜单打开时跳过不可选标题，避免初始键盘焦点落在标题上。
- 错误态在局部主题解析错误描边和组件底阴影，避免效果 OFF 时仍继承外层阴影；显式错误阴影覆盖继续优先。

### Changed
- 菜单图标尺寸、功能图标颜色和徽标留白接入组件 Token；保留显式图标档位，菜单文字在局部主题解析共享 Typography。
- 菜单项内边距、圆角、标题留白及普通/标题/选中颜色接入自有 Token，显式旧覆盖仍优先。
- 分组内分隔线接入独立颜色与左右、上下留白 Token，支持非对称留白；保留显式旧描边覆盖。
- 菜单表面、列间距、列上下留白/分隔线及分组间距/内边距接入 Cascader 自有 Token，保留显式旧覆盖。
- 输入框圆角、图标尺寸、背景/文字/图标色、展开描边及阴影接入组件 Token；描边不再占用布局高度，展开描边按 Figma 位于外侧。
- 输入框两档间距、内边距和插槽留白接入独立 Cascader Token，保留显式旧变量覆盖。
