# Select

## 3.1.0

### Fixed

- 普通文字触发器禁用态按组件 Token 分层淡化内容和文字，背景不再整体变淡；占位符跟随 Radix Trigger 的 data-placeholder 标记。

### Fixed
- 菜单行悬浮和键盘高亮背景在局部主题解析，不再继承根节点提前解析的默认颜色；显式 select-item-highlight-bg 覆盖仍优先。
- 输入触发器悬浮背景在局部主题中重新解析，保留显式 input-bg-hover 覆盖。
- 选中菜单项仅显示选择标记，不再添加主题色背景、文字色和阴影；默认、悬浮、键盘高亮和按下背景与未选中项一致。
- 标题菜单项左右图标使用独立 title/icon-default Token，普通菜单图标保持自身 Token，显式旧颜色覆盖继续优先。
- 正文颜色不再错误消费图标 Token，跟随菜单项文字颜色及选中/标题状态，避免自定义图标颜色影响正文。

### Added
- 新增 `SelectSearch`，复用 Input 并消费 Search 行留白与圆角 Token；支持键盘进入结果，过滤导致选中项卸载时保持输入焦点。过滤逻辑和空结果由调用方提供。

### Changed
- 尾部功能图标默认色、选中标记色及 Badge 外层横向留白消费独立 Token；自定义尾部图标无显式档位时跟随组件尺寸。
- 默认尾部功能图标使用菜单项宽度/槽高 Token；Checked 分支背景消费选中背景 Token，保留显式旧背景覆盖。
- 菜单左右图标按普通/标题组件 Token 设置尺寸与槽高，保留显式图标档位；人员项的表单单选/复选分支使用普通横向内边距。
- 标题、副标题颜色与附加功能区高度、末端留白、分隔线颜色接入组件 Token；修复副标题颜色被共享 Typography 继承规则覆盖。
- 菜单项间距、内边距、圆角及标题/人员项特殊留白消费独立组件 Token，显式旧间距覆盖继续优先。
- 菜单分组及分割线接入7项独立Token；左右留白归属每个分组，子菜单不再重复叠加留白。
- 菜单背景、边框、圆角、padding、分组间距及默认菜单文字消费组件Token，支持局部项目主题。
- 默认/展开/禁用背景、文字、图标、展开描边及阴影消费SelectInput Token；旧共享颜色覆盖继续优先。
- 输入框两档间距、外框/插槽padding、普通/全圆角及图标尺寸接入SelectInput Token；保留旧尺寸覆盖。

### Fixed
- 搜索框内 Enter 不再触发表单隐式提交；方向键进入结果后仍可按 Enter 选择。
- 菜单正文、分组标题和副标题在当前局部主题解析共享 Typography 指标；标题行使用 caption 档位，保留显式旧字号/行高覆盖。
- 修复元素间焦点移动被误判为窗口失焦，导致 Enter 选择和 Escape 关闭被拦截；键盘关闭后恢复输入框焦点。
- 子菜单关闭后保留选中项标签注册，修复选择子项后输入框显示为空；延迟收起时尊重子菜单内的键盘焦点。
- 共享输入字号、行高和图标插槽默认高度在局部主题中解析，避免继承外层已解析的密度值；保留显式旧覆盖。

## 3.0.0

### Added
- `SelectSubItem`：焦点在子菜单行上时可用 Up / Down / Home / End 在同层菜单项之间移动；展开方向键（RTL 下镜像）打开子菜单并把焦点送入首项，收起方向键或 Esc 关闭并把焦点送回该行
- 主菜单在 `SelectSubItem` 与 Radix `SelectItem` 混排时，方向键会把焦点送入/送出子菜单行（Radix 集合本身会跳过这些行）
- 子菜单面板内同样支持 Up / Down / Home / End，导航范围限定在当前面板

### Removed
- `SelectItem` / `SelectSubItem` 开启 `showBadge` 但未传 `badge` 时不再回填 `Text` 占位 Badge
- `SelectItem` / `SelectSubItem` 开启 `showMoreFunction` 但未传 `moreAction` 时不再回填 `Text` 占位 Link，尾部槽位整体不渲染
